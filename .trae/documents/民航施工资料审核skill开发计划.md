# 民航施工资料审核 Skill 开发计划

## 摘要

开发 `civil-aviation-doc-audit` Skill，面向民航机场改扩建项目，具备四大核心能力：
1. **OCR 识别**：扫描件施工资料的文字提取（PDF/图片 → 文字）
2. **规范合规审核**：基于 MH/T 5078 系列等民航规范，审核施工资料合规性
3. **运算规范审核**：审核资料中结构运算是否符合对应运算规范
4. **文档生成**：自动生成审核报告、整改通知书、合规检查清单

### 四大核心模块

#### 模块一：OCR 资料识别（扫描件处理）

**触发条件**：用户提供 PDF 扫描件或图片格式的施工资料

**流程**：
1. **格式识别**：判断输入文件类型（PDF/图片/电子文档）
2. **图片提取**：若为 PDF，使用 Python 脚本（pdf2image）提取页面为图片
3. **OCR 文字提取**：使用 Read 工具读取图片，AI 视觉能力提取文字
4. **结构化整理**：将提取的文字按表格/段落/签章区域分类整理
5. **质量校验**：标记识别置信度较低的段落，提示人工复核

**支持的扫描件类型**：施工日志、检验批质量验收记录、隐蔽工程验收记录、材料进场检验报告、竣工图、计算书（含手写公式和参数）

#### 模块二：规范合规审核

**触发条件**：用户提供施工资料，要求审核合规性

**流程**：
1. **工程类别识别**：判断资料涉及的工程类别（场道/空管/助航/弱电/供油）
2. **规范匹配**：通过 `obsidian search` 从知识库匹配对应规范（MH/T 5078.x）
3. **审核项建立**：读取规范条目，建立审核检查项清单
4. **逐项比对**：比对资料内容，记录符合/不符合/缺失
5. **输出审核结果**：结构化输出审核意见

**规范覆盖范围**：
| 工程类别 | 核心规范 | 辅助规范 |
|---------|---------|---------|
| 场道工程 | MH/T 5078.2-2024 | MH 5007-2017、MH 5006-2015、MH-T5011-2019 |
| 空管工程 | MH/T 5078.3-2024 | MH-T 5110-2015 |
| 助航设施 | MH/T 5078.4-2024 | MH-T5012-2022 |
| 弱电系统 | MH/T 5078.5-2024 | MH-T 5039-2019 |
| 供油工程 | MH/T 5078.6-2024 | MH 5034-2017 |
| 通用要求 | MH/T 5078.1-2024 | CCAR-165-R1、MH 5031-2025 |

#### 模块三：运算规范审核

**触发条件**：资料包含结构计算、地基验算、边坡分析等运算内容

**流程**：
1. **运算类型识别**：识别计算书中的运算类型
2. **规范查询**：通过 `obsidian search` 查询对应运算规范
3. **规范性检查**：计算方法合规性、参数取值范围、安全系数、边界条件、计算简图匹配度
4. **输出运算审核意见**

**常见运算场景及规范依据**：
| 运算类型 | 规范依据 | 审核重点 |
|---------|---------|---------|
| 地基承载力计算 | MH-T5027-2013 + GB 50007 | 计算方法、修正系数、承载力特征值 |
| 边坡稳定性分析 | MH-T5035-2017 + JGJ 120 | 分析方法、安全系数 |
| 挡土墙设计 | GB 50330 + MH-T5027 | 抗倾覆/抗滑移稳定系数 |
| 高填方沉降计算 | MH-T5035-2017 | 压缩模量取值、沉降计算方法 |
| 道面结构设计 | MH 5004-2025 / MH-T5010-2025 | 荷载模型、厚度计算方法 |
| 排水结构计算 | MH-T5005-2021 | 设计流量、断面尺寸 |

#### 模块四：文档生成

**触发条件**：审核完成后自动生成，或用户主动要求

**支持文档类型**：
1. **审核报告**（Markdown）— 项目信息/审核依据/审核结果/问题清单/整改建议/结论
2. **整改通知书**（标准格式）— 资料名称/不符合项/整改要求/时限/复核要求
3. **合规性检查清单**（表格形式）— 按规范条目逐项，标注符合/不符合/不适用/缺失

### references 文件设计

- **`audit-checklists.md`**：按五大工程类别分列审核检查项，对应 MH/T 5078.x 条款
- **`specification-mapping.md`**：资料类型 → 适用规范 → 具体条款映射表
- **`calculation-standards.md`**：运算场景的规范依据、计算方法要求、参数范围、安全系数
- **`document-templates.md`**：审核报告/整改通知/检查清单的标准模板

### Obsidian 集成方案

Skill 通过 `obsidian-cli` 实时访问知识库（单一数据源，规范更新自动同步）：

## 假设与决策

| 决策点 | 决策 | 理由 |
|--------|------|------|
| OCR 实现方式 | AI 多模态（Read 工具读取图片） | 无需额外安装 OCR 引擎，利用内置能力 |
| Skill 部署位置 | 项目级 `.trae/skills/` | 用户当前项目专用 |
| Obsidian 集成 | obsidian-cli 实时搜索读取 | 单一数据源，规范更新自动同步 |
| 运算审核深度 | 规范性检查（非数值验证） | AI 检查方法/参数/流程合规性，不替代专业计算软件 |
| 文档生成格式 | Markdown | 可转换为 HTML/Word 等格式 |
