    # MH 5029-2014 小型民用运输机场供油工程设计规范(标准信息)

    小型民用运输机场供油工程设计规范（MH 5029-2014）

标准信息：
标准号：MH 5029-2014
标准名称：小型民用运输机场供油工程设计规范
发布日期：2014年12月29日
实施日期：2015年3月1日
批准部门：中国民用航空局
主编单位：中国航空油料有限责任公司
状态：有效

说明：本标准由中国民用航空局发布，自2015年3月1日起施行。规定了小型民用运输机场供油工程设计的基本要求、工艺设计、总图布置、建筑设计、给排水与消防、电气、自控仪表等内容。

本标准为行业技术规范，全文需从中国民航出版社购买或通过标准信息服务机构获取。

（来源：中国民用航空局官网 http://www.caac.gov.cn/PHONE/SJ_IPHONE/JCS_IP/YWLJ_JCS/BZZZ_JCS/GCJSBZ/TZGG/201511/t20151111_11227.html）
