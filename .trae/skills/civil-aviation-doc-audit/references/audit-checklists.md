# 分专业审核检查清单

> 本清单按 MH/T 5078.1~5078.6-2024 各部分编制，每项对应具体条款。
> 实际审核时须通过 `obsidian read` 读取对应规范原文，确认最新条款内容。
> 清单中的"逻辑矛盾列"是触发铁律 9 的入口，凡是涉及"多方签认/数据累计/时间序列"的项目必须启动专项检查。

## 七、逻辑矛盾专项检查入口（铁律 9）

凡涉及以下情形的资料，**必须**触发逻辑矛盾专项检查（详见 `logic-conflict-patterns.md`）：

| 触发情形 | 重点检查维度 |
|---------|------------|
| 多份资料时间轴需对齐（施工日志/监理日志/检验批/材料报审） | 时间轴一致性 |
| 工程量累计需吻合（材料报审/施工记录/检验批/结算） | 数量累计 |
| 同一工序多专业人员签字（施工/质检/监理/检测） | 人员交叉 |
| 同一对象多份报告（材料复试/施工配合比/施工记录） | 因果一致性 |
| 前后资料引用同一规范/同一图纸版本 | 规范引用一致性 |
| 试验/检测数据需与施工工况匹配 | 试验一致性 |
| 隐蔽/签认需与后续工序时间匹配 | 状态描述一致性 |
| 整改前后资料需闭环（通知/回复/验证） | 整改闭环一致性 |
