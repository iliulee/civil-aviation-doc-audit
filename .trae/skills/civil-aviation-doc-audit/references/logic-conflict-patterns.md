# 逻辑矛盾识别模式库（铁律 9 配套）

> 本文件是铁律 9 的**具体识别规则**和**典型矛盾案例**。每次审核完成后，如发现新的高频矛盾模式，请补充到"九、典型真实案例"。

---

## 一、9.1 时间轴一致性（最重要）

### 9.1.1 检验批日期 ≥ 材料进场日期 ≥ 材料报审日期

**识别规则**：
- 材料报审日期（监理审批日期）→ 应在材料使用前
- 材料进场日期 → 应在报审合格后
- 检验批使用该材料的日期 → 应在进场之后
- **矛盾表现**：使用日期早于进场日期，或进场日期早于报审日期

**典型场景**：
- 钢筋焊接检验批日期 = 2024-03-15
- 钢筋进场日期 = 2024-03-18
- **矛盾**：用了还没进场的钢筋

### 9.1.2 隐蔽工程验收日期 ≤ 下道工序开工日期

**识别规则**：
- 隐蔽工程必须先验收再覆盖
- **矛盾表现**：下道工序已开工但隐蔽工程验收记录未形成

### 9.1.3 分项 ≤ 分部 ≤ 单位工程验收日期

**识别规则**：
- 验收顺序：分项 → 分部 → 单位
- 时间应顺向，不能跳跃
- **矛盾表现**：分部验收日期早于分项验收日期

### 9.1.4 监理通知单日期 ≤ 整改回复日期 ≤ 整改复核日期

**识别规则**：
- 通知 → 整改 → 复核，闭环
- **矛盾表现**：回复日期早于通知日期，或复核日期早于回复日期

### 9.1.5 设计变更日期 ≤ 实施日期

**识别规则**：
- 设计变更必须先审批后实施
- **矛盾表现**：已按变更施工但变更手续未下发

### 9.1.6 施工日志日期 vs 检验批/隐蔽/监理日志日期

**识别规则**：
- 同一工序在不同资料中的日期应一致
- **矛盾表现**：施工日志说"今日浇筑混凝土"，但当天检验批无记录

### 9.1.7 沉降/变形监测频率

**识别规则**：
- 监测方案规定频率：施工期多久一次、加载期多久一次
- 实际记录间隔应符合
- **矛盾表现**：方案要求3天一次，实际出现10天间隔

### 9.1.8 节假日异常施工

**识别规则**：
- 节假日有施工记录但无加班审批
- **矛盾表现**：国庆、春节有施工记录但无任何说明

## 二、9.2 数量累计一致性

### 9.2.1 检验批工程量累计 = 分项工程工程量

**识别规则**：
- 各检验批工程量加起来 = 分项工程总量
- **矛盾表现**：差值 > 5%（允许施工误差）

### 9.2.2 分项工程量累计 = 分部工程量

**识别规则**：同 9.2.1，向上累计

### 9.2.3 分部工程量累计 = 单位工程量 ≈ 竣工图工程量

**识别规则**：
- 累计到单位工程应与合同/竣工图基本一致
- 差异 > 3% 应说明原因

### 9.2.4 材料报审量 ≥ 实际使用量

**识别规则**：
- 进场材料不会比实际使用少
- **矛盾表现**：使用量 > 进场量（材料来源不明）

### 9.2.5 试验检测批次数量 ≥ 检验批数量

**识别规则**：
- 每个检验批都应有对应的检测报告
- **矛盾表现**：10个检验批只有5份检测报告

### 9.2.6 工程量清单 vs 合同清单 vs 结算清单

**识别规则**：
- 三个清单的工程量应逻辑一致
- **矛盾表现**：合同工程量与结算差异巨大

## 三、9.3 人员交叉一致性

### 9.3.1 施工日志记录的人员 = 实际作业班组 = 考勤表

**识别规则**：
- 三处出现的人员名单应一致
- **矛盾表现**：施工日志写"张三班组"，考勤表无此人

### 9.3.2 检验批签认人员 = 实际在岗人员

**识别规则**：
- 签字人应在项目部组织架构内
- **矛盾表现**：签字人不在岗或无此人

### 9.3.3 监理签字人员 = 派驻人员

**识别规则**：
- 监理签字应有该人员在本项目的授权
- **矛盾表现**：签字人未在本项目监理机构

### 9.3.4 同一签字人在不同资料的笔迹一致

**识别规则**：
- 笔迹特征稳定（可通过 OCR + 视觉对比）
- **矛盾表现**：明显不同笔迹的"同一人签字"

### 9.3.5 设计变更签字人 = 设计单位对应专业负责人

**识别规则**：
- 设计变更应由原设计单位相应专业负责人签字
- **矛盾表现**：非本专业或非本单位人员签字

### 9.3.6 项目经理/总监变更

**识别规则**：
- 变更应有正式手续
- 前后职责交接清晰
- **矛盾表现**：新经理已签字但无变更手续

## 四、9.4 状态描述一致性

### 9.4.1 同一检验批在不同资料中状态一致

**识别规则**：
- 检验批、隐蔽记录、监理日志、影像中描述应一致
- **矛盾表现**：检验批说"合格"，但监理日志说"局部返工"

### 9.4.2 不合格项整改闭环

**识别规则**：
- 不合格 → 整改通知 → 整改实施 → 复验合格
- **矛盾表现**：只有"不合格"，无后续整改记录

### 9.4.3 质量评估等级 vs 检测数据

**识别规则**：
- 评为"优良"应数据支撑
- 评为"合格"应无主控项目不合格
- **矛盾表现**：评为"优良"但合格率低

### 9.4.4 进度描述一致性

**识别规则**：
- 进度计划、实际进度、月报、监理评估应一致
- **矛盾表现**：进度计划说"完成 80%"，月报说"完成 50%"

## 五、9.5 签字一致性

### 9.5.1 笔迹稳定性

**识别规则**：
- 同一签字人在不同时间的笔迹应稳定
- 可通过 OCR 文字提取 + 视觉对比

### 9.5.2 签字日期

**识别规则**：
- 任何签字都应伴随日期
- **矛盾表现**：签字但无日期

### 9.5.3 执业印章

**识别规则**：
- 设计变更、关键工序验收、竣工验收 应有执业印章
- **矛盾表现**：关键文件仅有签字无印章

### 9.5.4 代签

**识别规则**：
- 代签本身不合规
- 授权代签需有书面授权
- **矛盾表现**：明显代签但无授权

## 六、9.6 因果逻辑一致性

### 9.6.1 质量问题无闭环

**识别规则**：
- 出现问题 → 整改/加固/变更/返工
- **矛盾表现**：记录中提到质量问题，无后续处理

### 9.6.2 重大变更的连锁响应

**识别规则**：
- 重大设计变更 → 施工方案变更 + 监理细则变更
- **矛盾表现**：设计已变更但方案/细则未更新

### 9.6.3 停工/复工闭环

**识别规则**：
- 暂停指令 → 复工报审 → 后续施工
- **矛盾表现**：停工指令无复工报审就继续施工

### 9.6.4 验收问题闭环

**识别规则**：
- 验收提出问题 → 整改 → 复验 → 通过
- **矛盾表现**：验收有未关闭问题但已签字

### 9.6.5 桩长偏差无支撑材料（铁律 12/14 配套）

**识别规则**：
- 实长 < 设计桩长且差值 > 20% → 必须有持力层验收记录、设计变更或现场签证
- **矛盾表现**：施工日志"其他情况"填"无"，但 90% 以上桩长不足设计值

### 9.6.6 同一桩号跨资料数据矛盾（铁律 15 配套）

**识别规则**：
- 同一桩号/同一条目在多份资料中数据不一致 → 至少有一份数据错误
- **矛盾表现**：DOC-A 中 Z418 实长 13.2m，DOC-B 中同一桩号实长 9.0m
- 此时应同时做单表自洽校验（铁律 12），自洽通过的值更可信

### 9.6.7 合计值来源不明（铁律 13 配套）

**识别规则**：
- 施工日志/汇总表有合计值，但原始施工记录无合计行 → 合计值来源不明
- **矛盾表现**：DOC-C 记录"33根，489.9m"，但 DOC-B 6页全部缺合计行
- 结果：合计值无原始记录支撑，无法确认真实性

## 七、9.7 规范引用一致性

### 9.7.1 同一项目规范版本统一

**识别规则**：
- 同类资料应引用同一版本规范
- **矛盾表现**：A检验批引 MH 5007-2017，B检验批引 MH 5007-2009

### 9.7.2 规范编号格式统一

**识别规则**：
- 同一项目应使用统一的编号格式
- 如 `MH/T 5078.1-2024` 应统一（不要混用 `MH/T5078.1-2024`）

### 9.7.3 规范引用与内容相关

**识别规则**：
- 引用的规范条款应与资料内容相关
- **矛盾表现**：路基资料引用桥梁规范

## 八、9.8 试验检测逻辑一致性

### 9.8.1 见证取样与报告编号对应

**识别规则**：
- 见证记录编号 = 试验报告编号
- **矛盾表现**：见证记录显示取样 3 组，报告只出 2 份

### 9.8.2 检测项目齐全性

**识别规则**：
- 规范要求检测的项目都应检测
- **矛盾表现**：规范要求 8 项，报告只检 5 项

### 9.8.3 不合格报告处理

**识别规则**：
- 不合格报告 → 复验/退货/降级使用
- **矛盾表现**：报告不合格但材料已使用且无复验

### 9.8.4 现场检测与实验室检测逻辑匹配

**识别规则**：
- 压实度+地基承载力、含水率+压实度 应数据匹配
- **矛盾表现**：现场压实度合格但承载力不合格

## 九、9.9 跨资料合计值反向验证（铁律 17 配套）

### 9.9.1 施工日志合计值 vs 施工记录实际合计

**识别规则**：
- 施工日志有合计值（如"33根，489.9m"）→ 必须与施工记录逐页核对
- **矛盾表现**：施工日志有精确合计值，但施工记录无合计行 → 合计值来源不明

### 9.9.2 合计值来源判定

**识别规则**：
- 有合计行 + 合计值正确 → 资料可信度提升
- 有合计行 + 合计值错误 → 数据汇总错误，需逐项修正
- 无合计行 + 有合计值 → 合计值来源不明，审计线索
- 无合计行 + 无合计值 → 资料不完整，需补全

### 9.9.3 合计数与分项数逻辑匹配

**识别规则**：
- 总桩数 = 各页小计桩数之和
- 总米数 = 各页小计米数之和
- **矛盾表现**：总桩数 33 根，但各页桩号差 = 32（Z420→Z415，差 5 个号，但共 6 根桩）→ 桩号跳跃需说明

### 案例 1：Z418 同一桩号跨资料数据矛盾（铁律 15 核心案例）

**矛盾类型**：9.6.6 同一桩号跨资料数据矛盾
**涉及资料**：
- 资料 A：DOC-A（未命名1.pdf），Z418 实长=13.2m，充盈系数=1.37
- 资料 B：DOC-B（扫描件.pdf），Z418 实长=9.0m，充盈系数=1.27
**矛盾点**：同一桩号 Z418，DOC-A 实长 13.2m，DOC-B 实长 9.0m，差异 4.19m。同时做高程自洽校验发现 DOC-B 中 Z418 的高程差=13.19m（≈13.2m），证实 DOC-A 数据更接近真实，DOC-B 实长被改过。
**发现方法**：AI 视觉全列提取 + 高程自洽校验（铁律 12）+ 跨资料交叉对比
**可能原因**：资料被修改（实长从 13.2m 改为 9.0m），修改意图可能是影响结算或验收
**严重程度**：高
**整改建议**：调取原始施工底稿验证，现场取芯，追溯资料修改原因

### 案例 2：DOC-B 缺合计行 vs DOC-C 有合计值（铁律 13/17 核心案例）

**矛盾类型**：9.6.7 合计值来源不明 / 9.9 跨资料合计值反向验证
**涉及资料**：
- 资料 B：DOC-B（扫描件.pdf），6页全部缺合计行
- 资料 C：DOC-C（施工日志），精确记录"33根，489.9m"
**矛盾点**：DOC-B 作为施工原始记录，6页底部无任何小计/合计行，但 DOC-C 中却出现了精确的合计值。合计值来源不是 DOC-B 本身。
**发现方法**：逐页检查表格底部结构
**可能原因**：DOC-B 是事后誊抄件，原始记录另有其件
**严重程度**：中
**整改建议**：调取原始记录核实，若原始记录已丢失需补充说明

## 十一、矛盾识别自动化建议

### 11.1 时间矛盾自动检测

```python
# 伪代码
def check_time_conflict(docs):
    events = extract_events(docs)  # 从资料中提取事件和日期
    for i, j in combinations(events, 2):
        if has_dependency(events[i], events[j]):  # 判断是否有先后依赖
            if events[i].date > events[j].date:  # 但日期相反
                flag_conflict(events[i], events[j])
```

```python
def check_quantity_sum(records):

```

### 11.3 人员交叉自动检测

```python
def check_person_consistency(records):
    log_persons = extract_persons(records['施工日志'])
    checkin_persons = extract_persons(records['考勤表'])
```
