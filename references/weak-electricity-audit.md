> 适用于民航运输机场航站楼及飞行区民航专业弱电系统工程的施工资料审核。
> 核心规范：MH/T 5078.5-2024（资料管理）+ MH/T 5018-2016（信息集成设计）+ MH/T 5017-2017（安防设计）+ 各子系统检测规范

## 二、各分部分项资料审核要点

### 2.1 信息集成系统（AODB/IMF）

**关键资料**：服务器安装记录、系统软件部署记录、接口联调记录、系统功能测试记录

**审核要点**（MH/T 5018-2016 + MH/T 5039-2019）：
- 服务器/存储配置：与设计一致，冗余配置（双机热备）
- 数据库部署：AODB 数据库表结构、数据字典与设计一致
- 接口测试：所有子系统接口（FIDS/PA/时钟/CCTV/离港/行李）全部联通
- 接口数据格式：IMF 消息格式符合设计规范
- 性能测试：并发用户数、响应时间满足设计指标
- 故障切换：主备切换时间 ≤ 30s
- 日志审计：操作日志记录完整

**技术参数阈值**：
- 服务器 CPU 利用率：常态 ≤ 70%
- 数据库响应时间：≤ 2s（简单查询），≤ 5s（复杂查询）
- 接口消息延迟：≤ 500ms
- 系统可用性：≥ 99.9%

**逻辑矛盾列**：与各子系统联动测试时序对照（铁律 9.1.1）

### 2.2 航班信息显示系统（FIDS）

**关键资料**：显示终端安装记录、控制器安装记录、系统功能测试记录

**审核要点**（MH/T 5015-2016 + MH/T 5032-2015）：
- 显示终端数量/位置：与设计点位图一致
- 终端安装高度/角度：符合设计
- 终端显示效果：亮度、分辨率、视角满足设计要求
- 信息刷新：航班信息更新延迟 ≤ 3s
- 模板切换：正常/延误/取消/登机等模板切换正常
- 中英文切换：显示正常
- 紧急模式：一键切换紧急信息显示
- 播放器/控制器冗余：主备切换正常

**技术参数阈值**：
- 信息刷新率：≤ 3s
- 终端分辨率：≥ 1920×1080
- 终端亮度：≥ 500 cd/m²（室内），≥ 1500 cd/m²（半室外）
- 播放器切换时间：≤ 10s

### 2.3 公共广播系统（PA）

**关键资料**：扬声器安装记录、功放安装记录、消防联动测试记录

**审核要点**（MH/T 5020-2016 + MH/T 5038-2019）：
- 扬声器布点：与设计点位图一致，声场覆盖无死角
- 声压级：背景噪声 + 15dB（一般区域），≥ 85dB（嘈杂区域）
- 功放功率：满足扬声器总功率要求，有冗余（≥ 20%）
- 分区广播：各分区独立可控
- 音源优先级：消防广播 > 应急广播 > 业务广播 > 背景音乐
- 消防联动：消防报警信号自动触发消防广播，切换时间 ≤ 3s
- 紧急话筒：最高优先级，一键全区广播
- 录音功能：自动记录所有广播内容

**技术参数阈值**：
- 声压级均匀度：≤ 4dB
- 语音清晰度（STI）：≥ 0.5
- 消防广播切换时间：≤ 3s
- 频率响应：100Hz~16kHz（± 3dB）
- 信噪比：≥ 70dB
- 功放冗余：≥ 20%（N+1 配置）

### 2.4 时钟系统

**关键资料**：母钟/GPS天线安装记录、子钟安装记录、对时测试记录

**审核要点**（MH/T 5019-2016 + MH/T 5040-2019）：
- 时间源：GPS/北斗双模，信号接收正常
- 母钟精度：≤ 1×10⁻⁹（日稳定度）
- 子钟显示：与母钟同步，偏差 ≤ 1s
- 子钟安装位置/数量：与设计一致
- NTP 授时：网络中所有设备可获取 NTP 时间
- 子钟类型：数字/指针，与设计一致
- 断电保持：母钟断电后 ≥ 72h 持续走时

**技术参数阈值**：
- 母钟守时精度：≤ 1ms/天
- 子钟同步精度：≤ 1s
- NTP 授时精度：≤ 10ms（局域网）
- 母钟 MTBF：≥ 50000h
- GPS 捕获时间：冷启动 ≤ 5min，热启动 ≤ 2min

### 2.5 安防监控系统（CCTV）

**关键资料**：摄像头安装记录、存储平台安装记录、系统功能测试记录

**审核要点**（MH/T 5017-2017）：
- 摄像头型号/数量/位置：与设计点位图一致
- 摄像头分辨率：与设计一致（一般 ≥ 1080P）
- 存储时长：≥ 30 天（航站楼）、≥ 90 天（飞行区/安检区）
- 视频压缩：H.265/H.264，码率与设计一致
- 夜视功能：低照度红外，有效距离满足设计
- 视频分析：人脸识别、车牌识别、物品遗留等智能分析功能
- 远程访问：授权用户可远程查看实时/回放
- 视频时间戳：与时钟系统同步，不偏差
- 防破坏：摄像头防拆报警

**技术参数阈值**：
- 存储时长：≥ 30 天（一般区域），≥ 90 天（重点区域）
- 帧率：≥ 25fps（实时），≥ 15fps（低带宽）
- 码率：2~8Mbps（1080P）
- 摄像头 MTBF：≥ 30000h
- 回放响应时间：≤ 3s

### 2.6 离港系统（CUTE/CUSS）

**关键资料**：柜台设备安装记录、自助设备安装记录、系统功能测试记录

**审核要点**（MH/T 5003-2016 + MH/T 5068-2023）：
- 柜台设备数量/位置：与设计一致
- CUSS（自助值机）设备：功能正常，支持多航空公司
- 登机牌打印机/行李条打印机：打印正常
- 护照阅读器/身份证阅读器：识别率 ≥ 99%
- 系统响应时间：值机/登机操作 ≤ 2s
- 中航信接口：通讯正常，数据同步
- 故障切换：本地服务器故障时备用模式可用

**技术参数阈值**：
- 值机操作响应时间：≤ 2s
- 登机操作响应时间：≤ 1s
- 证件识别率：≥ 99%
- 系统可用性：≥ 99.95%

### 2.7 综合布线系统

**关键资料**：线缆敷设记录、信息点安装记录、线缆认证测试报告

**审核要点**（MH/T 5021-2016 + GB 50312）：
- 线缆类型：六类/超六类/光纤，与设计一致
- 信息点数量/位置：与设计一致
- 线缆认证测试：100% 信息点通过认证
- 测试参数：衰减、近端串扰（NEXT）、回波损耗、接线图
- 光纤测试：衰减 ≤ 0.4dB/km（单模），≤ 3.5dB/km（多模）
- 配线架标签：端口号、房间号标识清晰
- 线缆整理：机柜内线缆整齐，理线器使用

**技术参数阈值**：
- 六类线 NEXT：≥ 35.3dB（100MHz）
- 六类线回波损耗：≥ 10dB（100MHz）
- 光纤衰减：≤ 0.4dB/km（单模 1310nm），≤ 0.3dB/km（单模 1550nm）
- 信息点面板高度：离地 300mm（标准）
- 无线 AP PoE 供电：符合 IEEE 802.3af/at

### 2.8 弱电机房

**关键资料**：UPS 安装记录、空调安装记录、防雷接地记录

**审核要点**（GB 50174 + GB 50303）：
- UPS 容量：满足设计负荷，有冗余（N+1）
- 电池后备时间：≥ 15min（或按设计）
- 精密空调：温湿度控制，温度 22±2°C，湿度 45%~65%
- 防雷接地：接地电阻 ≤ 1Ω（数据中心级）
- 等电位连接：所有金属设备接地
- 消防：气体灭火系统（非水喷淋）
- 环境监控：温湿度、漏水、烟感报警

**技术参数阈值**：
- 机房温度：22±2°C
- 机房湿度：45%~65% RH
- 接地电阻：≤ 1Ω（数据中心），≤ 4Ω（一般机房）
- UPS 效率：≥ 95%（在线式）
- 电池后备时间：≥ 15min

## 三、弱电系统专项常见错误（高频）

| 错误类型 | 典型表现 | 检查方法 | 规范依据 |
|---------|---------|---------|---------|
| 综合布线认证测试不全 | 只抽测部分信息点，未 100% 认证 | 查测试报告 | GB 50312 |
| 时钟系统未与 GPS 同步 | 子钟显示时间与标准时间偏差 | 查对时测试记录 | MH/T 5040-2019 |
| 消防广播联动失效 | 消防信号触发后广播未自动切换 | 查联动测试记录 | MH/T 5038-2019 |
| 视频存储时长不足 | 实际存储不足 30 天 | 查存储计算书 | MH/T 5017-2017 |
| 接口未做联调 | 子系统间数据不通 | 查接口联调记录 | MH/T 5039-2019 |
| 信息点标签缺失 | 配线架无标识，维护困难 | 查现场 | GB 50312 |
| UPS 电池未做放电测试 | 未验证电池实际后备时间 | 查放电测试记录 | GB 50174 |
| 摄像头时间戳偏差 | 与时钟系统不同步 | 查录像回放 | MH/T 5017-2017 |
| 离港系统未做压力测试 | 高峰时段系统响应慢 | 查压力测试报告 | MH/T 5068-2023 |
| 网络未做冗余测试 | 单链路故障导致业务中断 | 查网络冗余测试 | 设计要求 |

## 四、各子系统检测规范速查

审查弱电系统检测报告时，应核查是否满足以下检测规范：

| 子系统 | 检测规范 | 关键检测项 |
|--------|---------|-----------|
| 信息集成系统 | MH/T 5039-2019 | 接口联通、性能压力、故障切换、数据同步 |
| 航班信息显示 | MH/T 5032-2015 | 终端显示、信息刷新、模板切换、紧急模式 |
| 公共广播 | MH/T 5038-2019 | 声场覆盖、消防联动、音源优先级、声压级 |
| 时钟系统 | MH/T 5040-2019 | GPS 同步、子钟精度、NTP 授时、断电保持 |
| 离港系统 | MH/T 5068-2023 | 值机/登机操作、接口联通、压力测试 |
| 安防监控 | MH/T 5017-2017 | 摄像头覆盖、存储时长、视频分析、时间戳 |
| 综合布线 | GB 50312 | 认证测试、衰减、NEXT、回波损耗 |
| 弱电机房 | GB 50174 | 温湿度、接地、UPS、消防 |
