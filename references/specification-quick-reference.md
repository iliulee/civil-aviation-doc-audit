## 八、常见审核场景速查

### 场景 1：审核土方压实度检验批

1. 适用规范：MH/T 5078.2 第 4 章
2. 主控项目：压实度（≥设计值）
3. 一般项目：高程、平整度、横坡
4. 关联：测量记录、土工试验、碾压记录
5. **铁律 9.1.1 检查**：材料进场日期 ≤ 检验批日期

### 场景 2：审核混凝土面层检验批

1. 适用规范：MH/T 5078.2 第 6 章
2. 主控：抗弯拉强度、厚度
3. 一般：平整度、纹理深度
4. 关联：配合比、开盘鉴定、试件、钻芯
5. **铁律 9.1.7 检查**：28天试压日期准确性

### 场景 3：审核隐蔽工程验收记录

1. 适用规范：MH/T 5078.x 第 7 章
2. 关键：验收日期（必须在覆盖前）
3. 内容：验收项目、参与方、结论
4. **铁律 9.1.2 检查**：验收日期 ≤ 下道工序日期

### 场景 4：审核沉降观测

1. 适用规范：MH-T5035-2017 第 7 章
2. 关键：基准点、频率、稳定性
3. **铁律 9.1.7 检查**：观测频率连续性
4. **铁律 9.6.1 检查**：超限值时是否有处理

### 场景 5：审核设计变更

1. 适用规范：MH/T 5078.1 第 5 章
2. 关键：变更手续、实施日期
3. **铁律 9.1.5 检查**：变更日期 ≤ 实施日期
4. **铁律 9.6.2 检查**：方案/细则是否相应变更

### 场景 6：审核监理通知单

1. 适用规范：MH 5031 第 7 章
2. 关键：问题描述、整改要求、回复闭环
3. **铁律 9.1.4 检查**：通知 → 回复 → 复核的时序
