# 结构运算规范审核参考

> **重要边界**：本 Skill 只做"运算规范性检查"，不做"数值复算"。
> 即：只判断"用的方法对不对、参数取值有没有依据、流程是否合规"，不替设计/施工方算一遍。
> 实际审核时须通过 `obsidian read` 读取规范原文确认具体参数。

---

## 适用场景与触发条件

下列情形需启动运算审核：

- 资料中包含"计算书"附件
- 涉及深基坑、高填方、高边坡、大型模板、复杂地基处理等危大工程
- 道面厚度、排水流量、边坡稳定等设计参数与原设计不一致
- 设计变更涉及结构/几何参数调整
- 检测结果异常需复核（如压实度不合格需加密检测时）

## 一、地基承载力计算

| 维度 | 规范要求 | 审核动作 |
|------|---------|---------|
| **适用规范** | MH-T5027-2013《民用机场岩土工程设计规范》+ GB 50007-2011《建筑地基基础设计规范》 | 列出依据条款 |
| **常用方法** | 标准贯入试验法（SPT）、静力触探法（CPT）、平板载荷试验法、理论计算法 | 判定方法是否属规范推荐 |
| **方法选择** | 是否与场地条件、地基土类型匹配 | 大型/重要建（构）筑物应优先采用载荷试验 |
| **修正系数** | 深度修正、宽度修正是否在规范允许范围 | 查规范表，不替设计复算 |
| **承载力特征值** | 是否与勘察报告建议值一致，差异有无说明 | 比较不一致需追因 |
| **参数依据** | 土层参数（c、φ值、压缩模量）是否有勘察报告依据 | 查勘察报告编号 |
| **安全系数** | 承载力特征值的安全系数一般不小于 2.0（具体按规范要求） | 比对规范要求 |
| **边界条件** | 基础埋深、地下水位、荷载组合是否与实际工况一致 | 与施工图核对 |

## 二、边坡稳定性分析

| 维度 | 规范要求 | 审核动作 |
|------|---------|---------|
| **适用规范** | MH-T5035-2017《民用机场高填方技术规范》+ JGJ 120-2012《建筑基坑支护技术规程》 | 列出依据条款 |
| **常用方法** | 圆弧滑动法（瑞典法/Bishop 法）、折线滑动法（不平衡推力传递法） | 判定方法与边坡类型匹配 |
| **滑动面假设** | 是否合理（圆弧/折线/双折线） | 查分析剖面 |
| **工况覆盖** | 是否考虑最不利工况（持续降雨、地震、地下水骤降） | 列举所有工况 |
| **参数选择** | 抗剪强度参数是否考虑饱和/非饱和状态；峰值 vs 残余强度 | 查试验报告 |
| **安全系数** | 正常工况 ≥ 1.25~1.30；地震工况可适当降低 | 比对规范要求 |
| **支护结构** | 抗滑桩/锚索/挡墙的力是否平衡 | 不替设计复算，只校核方法 |
| **特殊工况** | 水位骤降、暴雨渗流、地震验算 | 必查项 |
| **监测要求** | 是否提出监测项目、点位、预警值 | 与监测方案对照 |

## 三、挡土墙设计计算

| 维度 | 规范要求 | 审核动作 |
|------|---------|---------|
| **适用规范** | GB 50330-2013《建筑边坡工程技术规范》+ MH-T5027-2013 | 列出依据条款 |
| **常用类型** | 重力式、扶壁式、加筋土、锚定板 | 类型与高度/地质条件匹配 |
| **土压力计算** | 朗肯/库仑方法选择 | 查选用依据 |
| **墙背填料** | 参数取值（γ、c、φ） | 查试验报告 |
| **稳定性验算** | 抗倾覆 ≥ 1.5（重力式）；抗滑移 ≥ 1.3（重力式）；地基承载力验算 | 比对规范要求 |
| **构造要求** | 泄水孔、伸缩缝/沉降缝、反滤层 | 查构造详图 |
| **地震工况** | 抗震设防烈度地区是否考虑 | 查抗震设防要求 |

## 四、高填方沉降计算

| 维度 | 规范要求 | 审核动作 |
|------|---------|---------|
| **适用规范** | MH-T5035-2017《民用机场高填方技术规范》 | 列出依据条款 |
| **常用方法** | 分层总和法、应力面积法 | 判定方法选用 |
| **计算深度** | 是否合理（按应力比或变形比确定） | 查计算深度 |
| **压缩层厚度** | 取值是否合理 | 与地层对比 |
| **沉降分类** | 是否区分瞬时沉降、固结沉降、次固结沉降 | 三种是否齐全 |
| **压缩模量** | 取值与勘察报告一致 | 查勘察报告 |
| **e-p 曲线** | 是否与土层匹配 | 查土工试验 |
| **控制标准** | 工后沉降量 ≤ 规范允许值（一般 50~100mm）；差异沉降坡度 ≤ 规范要求 | 比对规范要求 |
| **时间预测** | 固结系数、沉降-时间曲线 | 不替设计复算，只校核方法 |
| **监测要求** | 是否提出工后沉降监测要求 | 与监测方案对照 |

## 五、道面结构设计

| 维度 | 规范要求 | 审核动作 |
|------|---------|---------|
| **适用规范** | MH 5004-2025（水泥道面）或 MH-T5010-2025（沥青道面） | 列出依据条款 |
| **设计飞机** | 型号和运行频次是否正确 | 查设计任务书/可研 |
| **荷载模型** | 单轮/双轮/复轮，胎压、轮距是否与机型匹配 | 查设计输入 |
| **PCN 计算** | 道面等级号计算方法 | 查选用方法 |
| **参数取值** | 混凝土弯拉强度设计值、基层顶面当量回弹模量、土基反应模量 | 查试验报告 |
| **厚度计算** | 是否满足最小构造厚度要求；与类似工程经验对比 | 查类似工程 |
| **接缝设计** | 胀缝/缩缝间距、接缝传荷能力、拉杆/传力杆设置 | 查接缝设计图 |
| **变更** | 涉及厚度/接缝调整的变更是否重新计算 | 查变更后计算书 |

## 六、排水结构计算

| 维度 | 规范要求 | 审核动作 |
|------|---------|---------|
| **适用规范** | MH-T5005-2021《民用机场排水工程设计规范》 | 列出依据条款 |
| **设计流量** | 推理公式法/经验公式法选择 | 查选用依据 |
| **汇水面积** | 划分是否合理 | 查汇水图 |
| **设计重现期** | 跑道边沟一般 5 年一遇，截水沟 10~20 年 | 比对规范要求 |
| **径流系数** | 取值（按地表类型） | 查选用值 |
| **糙率取值** | 与沟体材料匹配 | 查选用值 |
| **断面验算** | 过水能力 ≥ 设计流量；流速在允许范围（防冲刷/防淤） | 比对规范要求 |
| **变更** | 涉及断面/坡度调整的变更是否重新计算 | 查变更后计算书 |

## 七、运算审核通用检查表（每次必走）

| 序号 | 检查维度 | 判定标准 |
|------|---------|---------|
| 7.1 | **依据规范** | 引用的规范编号、版本、年份是否正确，是否为有效版本 |
| 7.2 | **方法选择** | 所选方法是否为规范推荐/允许，是否与工况匹配 |
| 7.3 | **参数取值** | 每个关键参数是否有勘察/试验/设计依据文件 |
| 7.4 | **工况覆盖** | 是否考虑最不利工况（地震/暴雨/水位骤降/极端温度） |
| 7.5 | **安全系数** | 选用的安全系数是否满足规范最低要求 |
| 7.6 | **边界条件** | 几何尺寸、荷载、约束是否与图纸/方案一致 |
| 7.7 | **计算简图** | 简化是否合理（不替设计复算） |
| 7.8 | **签字盖章** | 计算人、审核人、审定人签字齐全 |
| 7.9 | **变更一致性** | 涉及变更的，是否有变更后计算书 |
| 7.10 | **资料闭环** | 计算书与图纸、方案、检测报告是否一致（触发铁律 9） |

## 八、运算审核流程

```
识别运算类型
    ↓
obsidian search 查询对应规范
    ↓
读取规范原文（obsidian read）
    ↓
检查 10 个维度（不替设计复算）：
  1. 依据规范   → 是否为有效版本
  2. 方法选择   → 是否为规范推荐/允许
  3. 参数取值   → 是否有依据
  4. 工况覆盖   → 是否齐全
  5. 安全系数   → 是否满足最低要求
  6. 边界条件   → 是否与实际一致
  7. 计算简图   → 简化是否合理
  8. 签字盖章   → 是否齐全
  9. 变更一致性 → 变更后是否重算
  10. 资料闭环 → 与其他资料是否一致
    ↓
输出审核意见（每项标注合规/不合规 + 依据条款）
```

## 九、运算审核与一般审核的边界

| 项 | 运算审核（本文件） | 一般审核（其他 references） |
|---|------------------|-------------------------|
| 是否复算数值 | ❌ 否 | ❌ 否 |
| 是否审核方法 | ✅ 是 | ➖ 不涉及 |
| 是否审核参数取值 | ✅ 是（只查依据，不复算） | ➖ 不涉及 |
| 是否审核安全系数 | ✅ 是（比对规范要求） | ➖ 不涉及 |
| 是否审核签字 | ✅ 是 | ✅ 是 |
| 是否触发铁律 9 | ✅ 是（资料闭环） | ✅ 是 |
| 输出物 | 审核报告"运算审核"章节 | 审核报告其他章节 |
