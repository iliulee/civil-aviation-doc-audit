# 空管工程专项审核要点

> 适用于民航运输机场空管工程（含导航、监视、通信、气象、空管自动化等）的施工资料审核。
> 核心规范：MH/T 4003.1-2021（导航台站场地）+ MH/T 4006.1~4-1998（导航设备技术要求）+ MH/T 5078.3-2024（资料管理）

---

## 二、各分部分项资料审核要点

### 2.1 导航台站选址与场地保护

**关键资料**：台站选址报告、场地保护方案、电磁环境测试报告

**审核要点**（MH/T 4003.1-2021 + GB 6364）：
- 台站坐标：与设计批复一致
- 场地保护区：导航台站临界区/敏感区已划定，无建筑物超限
- 电磁环境：台站电磁环境测试合格，无干扰源
- 台站标高：场地标高与设计一致
- 供电：双路供电或 UPS 冗余配置
- 通信：导航台到塔台/管制中心通信链路冗余

**技术参数阈值**：
- ILS 航向台前方保护区：宽度 ≥ 120m，长度 ≥ 3000m
- ILS 下滑台反射面：平坦度满足要求（± 15cm/30m）
- VOR/DME 台站净空：周围 300m 内无大型建筑物
- 电磁环境：保护率满足 GB 6364 要求

### 2.2 仪表着陆系统（ILS）

**关键资料**：设备开箱检验记录、天线安装记录、设备调试记录、飞行校验报告

**审核要点**（MH/T 4006.1-1998）：
- 航向台天线阵：天线数量、间距、高度与设计一致，基础牢固
- 下滑台天线：天线高度、安装位置与设计一致，反射面平整
- 航向台发射功率：与设计一致，满足覆盖范围
- 调制深度：航向 20%（90Hz/150Hz），下滑 40%（90Hz/150Hz）
- 频率：航向 108.1~111.95MHz，下滑 329.15~335MHz 配对
- 监控器：航向/下滑/内指点标监控器功能正常，告警时间 ≤ 10s
- 双机切换：主机故障自动切换，切换时间 ≤ 10s
- 遥控/遥测：监控信号到塔台/管制中心正常

**技术参数阈值**：
- 航向覆盖范围：± 10° 方位角 ≥ 25NM，± 35° ≥ 17NM
- 下滑覆盖范围：± 8° 方位角 ≥ 10NM
- 切换时间：≤ 10s
- 告警时间：≤ 10s（航向），≤ 5s（下滑）

**逻辑矛盾列**：飞行校验报告日期 vs 设备调试完成日期（铁律 9.1.1）

### 2.3 全向信标/测距仪（VOR/DME）

**关键资料**：设备开箱检验记录、天线安装记录、设备调试记录、飞行校验报告

**审核要点**（MH/T 4006.2-1998 + MH/T 4006.3-1998）：
- VOR 天线：天线高度、地网直径与设计一致
- DME 天线：与 VOR 合装或分装，位置与设计一致
- VOR 频率：108.0~117.95MHz
- VOR 方位精度：± 1°（标准），± 0.5°（精密）
- DME 应答效率：≥ 70%（或 100 架次/sec）
- DME 测距精度：± 0.1NM 或 ± 0.25% 距离
- VOR/DME 监控器：功能正常，告警时间 ≤ 10s
- 双机切换：自动切换，切换时间 ≤ 10s

**技术参数阈值**：
- VOR 方位精度：± 1°
- DME 应答效率：≥ 70%
- DME 测距精度：± 0.1NM
- 切换时间：≤ 10s
- VOR 覆盖范围：≥ 40NM（航路），≥ 25NM（终端）

### 2.4 雷达系统

**关键资料**：设备开箱检验记录、天线塔/天线安装记录、设备调试记录、覆盖测试报告

**审核要点**：
- 天线塔基础：混凝土强度满足设计，塔体垂直度 ≤ H/1000
- 天线安装：波导/馈线连接正确，驻波比 ≤ 1.5
- 一次雷达覆盖：≥ 60NM（航路），≥ 30NM（终端）
- 二次雷达覆盖：≥ 200NM（航路），≥ 60NM（终端）
- 目标检测概率：≥ 90%（一次雷达），≥ 99%（二次雷达）
- 雷达数据处理：目标跟踪、航迹关联、冲突告警功能正常
- 双机切换：自动切换，切换时间 ≤ 30s

**技术参数阈值**：
- 天线塔垂直度：≤ H/1000
- 馈线驻波比：≤ 1.5
- 目标检测概率：≥ 90%（PSR），≥ 99%（SSR）
- 切换时间：≤ 30s

### 2.5 自动气象观测系统（AWOS）

**关键资料**：传感器安装记录、标定记录、系统调试记录、数据对比测试报告

**审核要点**：
- 传感器安装位置：跑道两端 + 跑道中部（RVR），与设计一致
- 大气透射仪/前散射仪：安装高度 2.5m，标定合格
- 风传感器：安装高度 10m，标定合格
- 温湿度/气压传感器：标定合格
- 云高仪：安装位置合理，测量范围满足要求
- 跑道视程（RVR）计算：逻辑正确，覆盖 3 个区域
- 数据采集处理单元（DPU）：双机冗余，数据存储正常
- 气象数据显示终端：塔台/气象台/进近管制室均可用

**技术参数阈值**：
- 风传感器安装高度：10m
- RVR 传感器安装高度：2.5m
- 气压传感器精度：± 0.3hPa
- 温度传感器精度：± 0.2°C
- 风速精度：± 0.5m/s（≤ 10m/s），± 5%（> 10m/s）

### 2.6 通信系统（VHF/内话）

**关键资料**：设备安装记录、频率配置表、覆盖测试记录、录音系统测试记录

**审核要点**：
- VHF 频率：118.0~136.975MHz，民航专用频率
- VHF 天线：安装高度、位置与设计一致，驻波比 ≤ 1.5
- VHF 覆盖范围：≥ 200NM（高空），≥ 50NM（终端）
- 内话系统：席位配置与设计一致，通话/监听/转接功能正常
- 语音通信交换系统（VCSS）：路由配置正确
- 录音系统：全部席位录音，存储时长 ≥ 90 天
- 传输网络：SDH/微波/光纤，链路冗余，切换时间 ≤ 50ms

**技术参数阈值**：
- VHF 频率：118.0~136.975MHz，25kHz/8.33kHz 波道间隔
- 天线驻波比：≤ 1.5
- 录音存储时长：≥ 90 天
- 传输链路切换时间：≤ 50ms

### 2.7 飞行校验

**关键资料**：飞行校验报告（由校验中心出具）

**审核要点**：
- 飞行校验时间：设备安装调试完成后
- 校验项目：覆盖 ILS（航向/下滑/指点标）、VOR/DME、PAPI、雷达
- 校飞结论：合格/限用/不合格
- 限用条件：限制条件已记录并通知相关方
- 校飞报告签字：校验机组、管制单位、设备单位签字齐全
- 校飞周期：初次校飞 + 定期校飞（ILS 每 180 天，VOR 每 540 天）

**逻辑矛盾列**：校飞日期 vs 设备完成安装日期 vs 校飞报告签字日期（铁律 9.1.1）

## 三、空管工程专项常见错误（高频）

| 错误类型 | 典型表现 | 检查方法 | 规范依据 |
|---------|---------|---------|---------|
| 台站场地保护不满足 | 保护区有建筑物超限 | 查场地保护报告 | MH/T 4003.1-2021 |
| ILS 监控器告警时间超限 | 航向告警 > 10s | 查调试记录 | MH/T 4006.1-1998 |
| 飞行校验结论为"限用"未说明 | 限用条件未记录 | 查校飞报告 | ICAO Doc 8071 |
| 天线驻波比超标 | 驻波比 > 1.5 未处理 | 查天线测试记录 | 厂家技术手册 |
| 双机切换时间超限 | 切换 > 10s（ILS）或 > 30s（雷达） | 查切换测试记录 | 各设备技术要求 |
| 电磁环境测试未做 | 未做电磁兼容性测试 | 查电磁环境报告 | GB 6364 |
| 气象传感器未标定 | 出厂标定过期 | 查标定证书 | 厂家要求 |
| 录音系统存储时长不足 | 存储 < 90 天 | 查存储容量计算 | 民航局要求 |
| 通信链路无冗余 | 单链路故障导致业务中断 | 查网络拓扑 | 设计要求 |
| 校飞报告签字不全 | 缺少校验机组或管制签字 | 查校飞报告 | 校飞程序要求 |

## 四、导航设备技术要求速查

审查设备合格证和调试记录时，应核查是否满足以下技术规范：

| 设备类型 | 技术规范 | 关键指标 |
|---------|---------|---------|
| ILS（航向） | MH/T 4006.1-1998 | 航道精度 ± 0.015DDM，覆盖 ± 10° |
| ILS（下滑） | MH/T 4006.1-1998 | 下滑角 3° ± 0.075°，覆盖 ± 8° |
| VOR | MH/T 4006.2-1998 | 方位精度 ± 1°，覆盖 ≥ 40NM |
| DME | MH/T 4006.3-1998 | 测距精度 ± 0.1NM，应答效率 ≥ 70% |
| NDB | MH/T 4006.4-1998 | 覆盖 ≥ 50NM，频率 190~1750kHz |
| 台站场地 | MH/T 4003.1-2021 | 临界区/敏感区尺寸 |
| 监视台站场地 | MH/T 4003.2-2014 | 雷达站场地保护 |
