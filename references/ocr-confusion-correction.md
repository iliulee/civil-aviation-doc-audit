# OCR 字符混淆校正规则（施工资料专用）

> **设计意图**：RapidOCR 对手写施工资料的识别率约 85%，但剩余 15% 的错误集中在几个高频混淆对上，且这些错误恰好落在关键数值字段（桩号、充盈系数、桩长），导致大量误报。本文件固化施工资料场景下的 OCR 混淆校正规则，审核时自动执行。

## 一、高频混淆对（施工资料场景）

| OCR 识别值 | 可能原值 | 触发条件 | 校正动作 |
|-----------|---------|---------|---------|
| `2` 开头 + 3位数字 | `Z` + 3位数字 | 桩号列，且后续桩号有 Z 开头 | 标注"疑似桩号 Z→2 混淆"，列入待核实清单 |
| `1.0X` | `1.4X` 或 `1.6X` | 充盈系数列，X 为 6/8/9 | 标注"疑似充盈系数 4→0 混淆" |
| `0` 在小数位 | `4` 或 `6` | 充盈系数、竖直度等 0.X~1.X 范围数值 | 标注"疑似 4→0 或 6→0 混淆" |
| `1` 开头 + `.X` | `7.X` | 桩长列，且相邻行桩长在 7~8m | 标注"疑似 7→1 混淆" |
| `O` 或 `o` | `0` | 数字字段中的 O | 替换为 0 |
| `l` 或 `I` | `1` | 数字字段中的 l/I | 替换为 1 |
| `S` 或 `s` | `5` | 数字字段中的 S | 替换为 5 |
| `B` | `8` | 数字字段中的 B | 替换为 8 |

## 二、上下文感知校正规则

### 规则 1：桩号前缀一致性

**识别规则**：
- 同一份资料中，桩号列应使用统一前缀（Z/PH/CFG 等）
- 若大部分桩号以 Z 开头，个别以 2 开头 → 高概率是 Z→2 混淆
- **校正动作**：将疑似 2 开头的桩号标注为"OCR 存疑：2 可能是 Z"，列入待核实清单，不直接判定为"桩号格式不统一"

### 规则 2：充盈系数范围校验

**识别规则**：
- 碎石桩充盈系数正常范围：1.1~1.5（极少数到 1.6）
- 若 OCR 识别值 < 1.0 或 > 1.6 → 高概率是 OCR 错误
- 常见混淆：1.46→1.06（4→0）、1.38→1.98（3→9）
- **校正动作**：
  - 识别值 < 1.0 → 标注"OCR 存疑：充盈系数 < 1.0 不合理，疑似 OCR 误读"
  - 识别值 > 1.6 → 标注"OCR 存疑：充盈系数 > 1.6 需核实"
  - 均列入待核实清单，不直接判定为"数据异常"

### 规则 3：桩长一致性范围

**识别规则**：
- 同一施工区域的桩长通常在 ±30% 范围内波动
- 若某根桩桩长仅为相邻桩的 50% 以下，且备注列无"致岩""入岩"等说明
- → 可能是 OCR 误读（如 13.7→8.7 的 3→8 混淆，或 1→8 混淆）
- **校正动作**：标注"OCR 存疑：桩长突变可能是 OCR 误读"，列入待核实清单

### 规则 4：高程自洽反向验证

**识别规则**：
- 桩长 = 桩顶高程 - 桩底高程（铁律 12）
- 若 OCR 识别的桩长 ≠ 高程差，但偏差在 0.5~2.0m 范围
- → 高概率是 OCR 误读了某个数字（如 13.7→13.1、9.0→8.0）
- **校正动作**：
  - 用高程差反推可能的真实桩长
  - 标注"OCR 存疑：桩长 X.Xm 与高程差 Y.Ym 不一致，高程差反推真实桩长约 Z.Zm"
  - 列入待核实清单，不直接判定为"数据造假"

## 三、校正执行流程

```
OCR 提取表格数据
      ↓
Step 1: 逐字段检查混淆对（第一节规则表）
      ↓ 命中混淆对 → 标注"OCR 存疑"
Step 2: 上下文感知校正（第二节规则）
      ↓ 桩号前缀不一致 → 检查是否 Z→2
      ↓ 充盈系数越界 → 检查是否 4→0
      ↓ 桩长突变 → 检查是否 3→8 或 1→8
      ↓ 高程自洽失败 → 反推真实桩长
Step 3: 生成 OCR 待核实清单
      ↓
Step 4: 对待核实清单中的关键字段，使用 AI 视觉重新读取
      ↓ AI 视觉读取结果与 OCR 结果不一致 → 以 AI 视觉为准（标注"视觉复核值"）
      ↓ AI 视觉读取结果与 OCR 结果一致 → 确认为真实数据异常（非 OCR 误读）
Step 5: 输出校正后的数据 + 待核实清单
```

## 四、与审核流程的集成

| 审核环节 | 集成方式 |
|---------|---------|
| Step 2 OCR 提取后 | 自动执行混淆校正（第一节 + 第二节） |
| Step 3 数据质量检测前 | OCR 待核实清单已生成，数据质量检测基于校正后数据 |
| Step 8 报告生成 | OCR 待核实清单单独列为报告一章，每项含"OCR 原始值""校正建议值""核实状态" |

## 五、关键原则

1. **不自动替换** — 校正规则只标注"存疑"，不直接修改 OCR 识别值
2. **AI 视觉复核优先** — 对存疑字段，用 AI 视觉能力重新读取原图，比盲目替换更可靠
3. **高程自洽是硬证据** — 高程差反推的桩长比 OCR 识别值更可信
4. **待核实清单不阻塞审核** — 存疑项标注后继续审核流程，但在报告中必须体现
