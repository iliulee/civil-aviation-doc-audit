# 场道工程专项审核要点

> 适用于民航运输机场场道工程（含跑道、滑行道、停机坪、联络道）的施工资料审核。
> 核心规范：MH/T 5078.2-2024 + MH 5007-2017（质量检验评定）+ MH 5004-2025（水泥道面设计）+ MH-T5010-2025（沥青道面设计）

---

## 二、各分部分项资料审核要点

### 2.1 土方工程

**关键资料**：
- 测量放线记录（含控制点引测、断面复测）
- 土方开挖/填筑检验批（主控项目：压实度；一般项目：高程、平整度）
- 隐蔽工程记录（地基验槽、软基处理）
- 强夯/碾压试验段记录
- 沉降观测记录（高填方必查）
- 土壤试验报告（击实、含水率、压实度）

**审核要点**：
- 强夯施工记录：夯击能、夯锤重量、落距、夯击遍数、间隔时间
- 高填方分层厚度（一般≤30cm）+ 压实度（≥96%）
- 沉降观测：基准点稳定性、观测频率、沉降速率
- 边坡坡度：设计文件 vs 实际测量
- 特殊土处理：换填材料、深度、范围、检测报告

### 2.2 基层工程

**关键资料**：
- 原材料报审（碎石、砂砾、水泥等）
- 配合比设计报告 + 配合比审批
- 混合料击实试验
- 基层检验批（厚度、压实度、平整度、纵断高程、横坡）
- 7天无侧限抗压强度（水泥稳定类）
- 弯沉检测

**审核要点**：
- 配合比审批程序（先设计→施工→监理审批）
- 7天强度 vs 设计要求（一般 3-5 MPa）
- 弯沉值：设计文件要求 vs 实测值
- 养生记录（覆盖、洒水、养生期≥7天）
- 段落划分：连续施工段落 vs 检验批对应

### 2.3 水泥混凝土面层

**关键资料**：
- 原材料报审（水泥、骨料、钢筋、外加剂）
- 混凝土配合比设计报告
- 混凝土浇筑申请单
- 开盘鉴定（首盘鉴定 + 每班次）
- 混凝土试件留置（标准养护 + 同条件）
- 28天抗弯拉强度评定
- 面层检验批（厚度、平整度、纹理深度、抗滑摩擦系数）
- 胀缝/缩缝/施工缝记录
- 道面刻槽记录

**审核要点**：
- 抗弯拉强度：试件组数（每 100m³ 一组）、评定方法
- 平整度：3m 直尺法或 IRI 指数
- 纹理深度：铺砂法
- 胀缝：传力杆设置、胀缝板材料、灌缝深度
- 缩缝：切缝时间（混凝土强度 8-12 MPa 时切）、切缝深度
- 拉杆/传力杆：规格、间距、位置、保护层厚度
- 试件评定：统计法/非统计法、与设计值对比
- 钻芯取样：28天后、抗弯拉强度复核

### 2.4 沥青混凝土面层

**关键资料**：
- 原材料报审（沥青、骨料、矿粉、改性剂、聚丙烯腈纤维）
- 目标配合比 + 生产配合比 + 配合比审批
- 马歇尔试验
- 沥青混合料检验批（厚度、压实度、平整度、渗水系数、构造深度、摩擦系数）
- 沥青含量抽提试验
- 温度记录（出厂、到场、摊铺、碾压）
- 碾压记录（初压、复压、终压）

**审核要点**：
- 配合比：目标→生产→施工 三阶段
- 温度控制：到场温度≥规定、摊铺温度、终压温度
- 压实度：双控指标（理论密度 + 试验段密度）
- 渗水系数：道面（≤200ml/min）、桥面（更严）
- 厚度：钻孔取样 或 地质雷达检测
- 接缝：纵缝热接缝、横缝平接缝
- 改性沥青/SMA 专项要求

### 2.5 排水工程

**关键资料**：
- 测量放线
- 沟槽开挖检验批
- 垫层/基础检验批
- 砌体/混凝土检验批
- 盖板/涵管安装记录
- 闭水试验
- 沟槽回填压实度

**审核要点**：
- 沟底纵坡：设计坡度 vs 实测
- 沟槽尺寸：宽度、深度、边坡
- 砌体砂浆饱满度（≥80%）
- 涵管接缝处理、闭水试验
- 回填压实度（管顶 50cm 内用细料，分层夯实）
- 跌水/急流槽位置、跌差

### 2.6 沉降/变形监测

**关键资料**：
- 监测方案（专项）
- 基准点/工作基点埋设
- 初始值测定
- 定期监测记录
- 监测成果报告（含沉降-时间曲线）
- 预警/报警记录

**审核要点**：
- 监测方案：经专家论证、监理审批
- 基准点：数量、稳定、复测周期
- 监测点：布点密度（高填方必查）
- 观测频率：施工期、加载期、间歇期
- 沉降速率：设计允许值、预警值、报警值
- 沉降预测：双曲线法/三点法/Asaoka法
- 异常处理：超预警时的应急响应记录

### 2.7 测量资料

**关键资料**：
- 控制点交接桩记录
- 控制测量记录（平面、高程）
- 施工放样记录
- 复测记录
- 竣工测量记录

**审核要点**：
- 控制点：等级、精度、稳定性
- 平面控制：附和/闭合差
- 高程控制：每 km 高差中误差
- 坐标系统：是否与设计一致（如 CGCS2000、北京54）
- 高程系统：1985 国家高程基准
- 测量人员：持证（测量员/工程师证）
- 测量仪器：检定证书有效期

## 三、场道工程专项常见错误（高频）

| 错误类型 | 典型表现 | 检查方法 |
|---------|---------|---------|
| 高填方分层超厚 | 一次填筑>50cm，无过程检测 | 查施工日志+沉降观测 |
| 强夯未间隔 | 连续夯击未间隔，夯击能不足 | 查强夯记录 |
| 胀缝传力杆位置偏差 | 传力杆偏位>5mm | 查检验批+影像 |
| 缩缝切缝过晚 | 出现不规则收缩裂缝 | 查切缝记录 |
| 沥青到场温度不足 | 现场温度<规范要求 | 查温度记录 |
| 配合比未经审批先施工 | 配合比未审批已开始 | 查配合比审批表日期 vs 开盘日期 |
| 试件漏留 | 浇筑量>100m³未留试件 | 查试件台账 vs 浇筑记录 |
| 28天强度未评定 | 工程已验收未做强度评定 | 查强度评定报告 |
| 沉降观测中断 | 关键期未观测 | 查观测记录连续性 |
| 测量坐标系错误 | 误用其他项目坐标系 | 查控制点交桩记录 |
