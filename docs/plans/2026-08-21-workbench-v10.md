# 资料员工作台 v10 实施方案

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把散落的 9 类审核 HTML 页面整合为一个"资料员工作台"，一次加载数据、模块共享；**v1 本期可用，v2 把核对编辑器真正并入**。所有通用基建件用 GitHub 现成轮子，不手写。

**Architecture:** 使用 `npm + Vite` 构建（用户已确认可用开源依赖）。编辑器本期保持独立文件由外壳跳转打开（大方向不变），**v2 用 postMessage 将其并入工作台标签页**。数据层采用项目已验证的双模加载（HTTP fetch / File System Access API 目录句柄）+ IndexedDB 句柄持久化实现"一键恢复授权"。file:// 协议 CORS 限制是既定事实，故 v1 用 Vite dev server + 产物 `dist/` 支持部署，配合现有的 File System Access API 离线写回。

**Tech Stack:** Vite · 引入 **SortableJS（拖拽）** + **SheetJS/xlsx（Excel 导出）** + ECharts（离线）· tokens.css 设计令牌 · IndexedDB · pytest（Python 后端回归）· **Playwright + webapp-testing（前端真浏览器测试）**

## 一、关键架构决策

### D1：编辑器并入策略 —— 本期独立，v2 并入

- **v1（本轮）**：编辑器保持独立文件，外壳"数据核对"菜单跳转打开。布局不变（左PDF右表格对比）。**搭好并入接口**：工作台监听 `message` 事件 + 编辑器暴露 `window.postMessage` 的版本查询协议，为 v2 铺路。
- **v2（下一轮）**：用 postMessage 把编辑器作为工作台标签页真正并入（`iframe` + `postMessage` 传 index.json 变更/目录句柄），做到一个页面全搞定，布局仍不变。
- 理由：v1 直接把 177KB 编辑器搬进外壳 = 重写状态机，高风险，违背"不造车轮"。分期是合理工程决策。

### D2：IndexedDB 句柄持久化 = 解决"重复加载"正解

Chrome 86+ 允许把 `FileSystemDirectoryHandle` 存入 IndexedDB，下次会话 `queryPermission()` 检查 + `requestPermission()` 一键恢复（无需重新翻目录树）。data-editor 目前只存项目名（`last_loaded_project`）。外壳与编辑器都加此能力；v2 并入后此能力自然顺延。

### D3：看板数据映射（真实字段，来自测试21 index.json 实测）

```
documents[] 字段：
  human_verified      → 🟢 已核对列
  pending_verification → 🟡 待核对/存疑列
  quality_alerts / confusion_suspects → 卡片角标（存疑条数）
  audit_status        → 审核状态徽章
  extraction_mode     → 卡片类型标识（ocr=扫描件/meta_xlsx=电子表）
  professional / doc_type / subcategory → 卡片分组维度
  last_updated        → 排序
顶层数组：corrections（修正留痕）、gaps（断档）
```

### D4：数据库评估结论（不迁 SQLite）

v1 保持 JSON 数据底座。仅两个加固：① `atomicWriteJSON()`（临时文件+改名）② 写前自动备份上一版到 `backups/`。SQLite 挂账为后置观察项（跨项目聚合卡顿时再议，走 8765 服务）。

### D5：构建与部署

- 开发：`npm run dev` → Vite dev server（解决了 file:// 下 fetch 被 CORS 拦的问题，可用 fetch 直读 index.json）
- 生产：`npm run build` → `dist/` 静态目录，可被 build_foundation 复制进数据底座
- 部署产物仍是**浏览器可直接打开的 HTML**，File System Access API 写回在 file:// 下照样可用；HTTP 模式下用 fetch 直读

```js
// src/data.js —— 工作台数据层（纯浏览器 API，无外部依赖）
export const WB = {
  index: null, foundationDirHandle: null, indexFileHandle: null,
  loadMode: null, onDataLoaded: null,
  DB_NAME: 'wb_handles', STORE: 'handles', KEY: 'last_foundation_dir',
};

function _idbOpen() {
  return new Promise((res, rej) => {
    const rq = indexedDB.open(WB.DB_NAME, 1);
    rq.onupgradeneeded = () => rq.result.createObjectStore(WB.STORE);
    rq.onsuccess = () => res(rq.result);
    rq.onerror = () => rej(rq.error);
  });
}
async function saveDirHandle(h) {
  const db = await _idbOpen();
  await new Promise((res, rej) => {
    const tx = db.transaction(WB.STORE, 'readwrite');
    tx.objectStore(WB.STORE).put(h, WB.KEY);
    tx.oncomplete = res; tx.onerror = () => rej(tx.error);
  });
  db.close();
}
export async function restoreLastHandle() {   // v1 用；v2 并入时编辑器复用
  try {
    const db = await _idbOpen();
    const h = await new Promise((res, rej) => {
      const rq = db.transaction(WB.STORE, 'readonly').objectStore(WB.STORE).get(WB.KEY);
      rq.onsuccess = () => res(rq.result); rq.onerror = () => rej(rq.error);
    });
    db.close();
    if (!h) return false;
    const p = await h.queryPermission({ mode: 'readwrite' });
    if (p !== 'granted') { if (await h.requestPermission({ mode: 'readwrite' }) !== 'granted') return false; }
    await _loadFromHandle(h); return true;
  } catch { return false; }
}
export async function pickProjectFolder() {
  if (!window.showDirectoryPicker) return false;
  try {
    const root = await window.showDirectoryPicker();
    let fdir = await root.getDirectoryHandle('数据底座').catch(() => null);
    let idx = fdir ? await fdir.getFileHandle('index.json').catch(() => null) : null;
    if (!idx && fdir) { idx = await fdir.getFileHandle('index.json').catch(() => null); }
    if (!idx) { fdir = root; idx = await root.getFileHandle('index.json').catch(() => null); }
    if (!idx) return false;
    await _loadFromHandle(fdir, idx);
    await saveDirHandle(fdir);
    return true;
  } catch { return false; }
}
async function _loadFromHandle(fdir, idx) {
  const fh = idx || await fdir.getFileHandle('index.json');
  const file = await fh.getFile();
  WB.index = JSON.parse(await file.text());
  WB.foundationDirHandle = fdir; WB.indexFileHandle = fh; WB.loadMode = 'fsapi';
  try { localStorage.setItem('last_loaded_project', WB.index.project_name || ''); } catch (e) {}
  if (WB.onDataLoaded) WB.onDataLoaded();
}
export async function autoLoad() {   // HTTP 模式
  try {
    const r = await fetch('./index.json', { cache: 'no-store' });
    if (r.ok) { WB.index = await r.json(); WB.loadMode = 'fetch';
      if (WB.onDataLoaded) WB.onDataLoaded(); return true; }
  } catch { /* file:// 属正常 */ }
  return false;
}
export async function atomicWriteJSON(filename, obj) {   // 原子写 + 自动备份
  if (!WB.foundationDirHandle) throw new Error('未持有目录句柄');
  const fh = await WB.foundationDirHandle.getFileHandle(filename, { create: true });
  const prev = await fh.getFile();
  if (prev.size > 0) {
    try {
      const bdir = await WB.foundationDirHandle.getDirectoryHandle('backups', { create: true });
      const w = await (await bdir.getFileHandle(filename + '.bak', { create: true })).createWritable();
      await w.write(await prev.arrayBuffer()); await w.close();
    } catch (e) { /* 备份失败不阻断 */ }
  }
  const w = await fh.createWritable();
  await w.write(JSON.stringify(obj, null, 2)); await w.close();
}
```
