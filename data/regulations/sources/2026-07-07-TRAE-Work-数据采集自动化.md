# 用 TRAE Work 实现数据采集分析自动化

> 美妆行业数据分析师 Damond 用 TRAE Work + Skill + 飞书，把每周 3 小时的人工数据采集分析彻底无人值守化。

## 核心观点

- **三层自动化架构**：执行层（Skill）→ 调度层（定时任务）→ 协作层（飞书云文档），把"我的电脑能跑"升级成"数据自动出现在团队空间"
- **分段验收是关键**：作者没有让 AI 一次写完所有代码，而是把流程拆成"登录验证→概览采集→明细采集→清洗→合并→上传"多个可肉眼验收的步骤
- **可执行的校验胜过口头描述**：不要只说"按钮好像没点到"，要写成"检测到 X 元素则操作，否则停止并截图"

## 关键概念

- **TRAE Work**：字节跳动的 AI 编程自动化平台，支持 Skill 封装、定时任务和飞书集成
- **Skill 封装**：将完整操作流程（安装依赖→采集→清洗→合并→校验）打包成一个可复用的自动化模块
- **数据校验层**：每条数据必须通过行数检查、字段完整性检查、单位换算检查后才算成功

## 与其他素材的关联

- 与 [[Codex]]、[[Claude Code]] 同属 AI 编程工具，但 TRAE Work 更强调 Skill+飞书的闭环自动化
- 与 [[多智能体工作流]] 主题相关，作者将流程拆解为多个可独立验证的阶段
- 用户日常使用 Trae + 提示词爬取数据，此文可直接借鉴其三层架构和分段验收方法
