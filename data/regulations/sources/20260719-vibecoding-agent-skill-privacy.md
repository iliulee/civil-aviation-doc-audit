# 初学 Vibe Coding 第二篇 —— 用 Agent+skill 手把手教你用 Agent 做一个照片隐私清除工具

> 来源：微信公众号 | 2026-07-19 | 关键词：Vibe Coding、Agent、Skill、照片隐私清除、AI工具

## 核心观点

Vibe Coding 进阶教程，讲解如何用 Agent + Skill 的组合方式开发照片隐私清除工具，引入模块化开发思维。

## 关键概念

- **Agent**：具备自主推理和执行的 AI 实体，可以调用工具和 Skill 完成任务
- **Skill**：将特定功能的经验打包成可复用的模块
- **Agent + Skill 组合**：Agent 负责理解和规划任务，Skill 负责执行具体功能模块
